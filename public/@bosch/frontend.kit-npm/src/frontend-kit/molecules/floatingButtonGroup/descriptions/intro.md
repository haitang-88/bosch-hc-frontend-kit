The *Floating button group* is a collection of regular button variants. Each of the button should be
of the same *group*, *groupType* and same constellation of *icon* and *label*.
Other than that every floating button variant can be used inside the *Floating button group*.

Also each *Floating button group* comes with it own background definition, e.g. `-primary`, which can be changed
to one of the three regular backgrounds.

<div class="frontend-kit__notification a-notification -neutral"><i class="a-icon ui-ic-alert-warning"></i><div class="a-notification__content">
    Since there is a wide variety of buttons, not all possible combinations are shown. The <strong>Brand</strong> Group will be shown in all cases.
    <strong>Neutral</strong> and <strong>Destructive</strong> will be shown in a reduced set.
</div></div>


## Advice for usage

The amount of *floating buttons* inside the *Floating button group* is not limited, but nevertheless comes with restrictions.

<div class="frontend-kit__notification a-notification -warning"><i class="a-icon ui-ic-alert-warning"></i><div class="a-notification__content">
    The <strong>Floating button group</strong> does <strong>not</strong> have any capabilities of line breaking behavior, therefore when implement
    component, enough space needs to be created for the component.
</div></div>
