Animated icons are a subset of Bosch Icons that are animated using [Lottie Web](https://github.com/airbnb/lottie-web). All scripts needed to run the animation are loaded automatically if an animated icon is used.

See the table [below](#id-all-animated-icons) for all available icon and their corresponding names.

## How to use

1. copy the base code snippet for one icon from [here](#id-single-icon)
1. look up the icon you want to use
1. copy the name of the icon
1. adjust the data-attribute `data-icon-name` of the surrounding div to the name of the icon
1. adjust the class and title of the `<i></i>` tag
