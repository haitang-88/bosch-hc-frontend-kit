There are 3 primary backgrounds: `-primary`, `-secondary` and `contrast`.

Each of which can be elevated using the utility classes `-floating-shadow-s`, `floating-shadow-m` or `floating-shadow-l`.

The `-dimmed` can be used to add a backdrop.
