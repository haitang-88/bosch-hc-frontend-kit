The Split button, behaves similar to a dropdown. Inside the Split button dropdown
every variant of the *menuItem* can be used, as the component uses the *menuGroup*.

<div class="frontend-kit__notification a-notification -neutral"><i class="a-icon ui-ic-alert-warning"></i><div class="a-notification__content">
  Since there is a wide variety of split buttons, not all possible combinations are shown. The <strong>Brand</strong> Group will be shown in all cases.
  <strong>Neutral</strong> and <strong>Destructive</strong> will be shown in a reduced set.
</div></div>
